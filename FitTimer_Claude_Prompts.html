Summary: What This App Does

  1. Open app → Pick your profile (or create one: name, height, weight, goal)
  2. Pick duration → 9 / 15 / 30 / 45 minutes
  3. Press START → Circular ring fills up as you work out
  4. Timer finishes → Celebration! Session auto-saved. Zero input needed.
  5. Need to stop early? → STOP button → choose Record (saves partial) / Discard / Continue
  6. Check history → Calendar view with green dots on workout days, monthly/yearly stats
  7. Multiple people → Each person has their own profile and data
  8. Export data → Download JSON backup from Profile tab
Tech stack: Pure HTML + CSS + JavaScript. IndexedDB for storage. No server, no installs, no accounts. Just one HTML file opened in a browser.
